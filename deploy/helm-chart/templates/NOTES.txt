SynapseMemory {{ .Chart.Version }} (app {{ .Chart.AppVersion }}) installed as release "{{ .Release.Name }}".

PostgreSQL is an EXTERNAL dependency — this chart does not deploy a database.
Do not send bootstrap or migration credentials to the application pods.

1. Create the runtime Secret "{{ .Values.secrets.existingSecret | default (printf "%s-secret" (include "synapse-memory.fullname" .)) }}" with:
   SYNAPSE_API_KEY, SYNAPSE_ENCRYPTION_KEY, SYNAPSE_APP_DB_PASSWORD,
   REDIS_PASSWORD (optional), and the key for the selected embedding provider
   (GEMINI_API_KEY for gemini; OPENAI_API_KEY for openai). The DB password here
   belongs to config.dbUser (normally synapse_app), not a superuser.

2. Provision pgvector PostgreSQL and confirm it is reachable at
   {{ .Values.config.dbHost }}:{{ .Values.config.dbPort }}/{{ .Values.config.dbName }}.

3. Before traffic reaches the pods, create runtime and migration roles and apply
   schema as the distinct non-superuser migration role. Run this from a trusted
   workstation/CI runner with the provisioner and SDK source installed. Use
   independent bootstrap, migration, and runtime passwords:
     export SYNAPSE_BOOTSTRAP_DATABASE_URL="postgresql://postgres:<bootstrap-password>@<host>:5432/<db>"
     export SYNAPSE_MIGRATION_DATABASE_URL="postgresql://synapse_admin:<migration-password>@<host>:5432/<db>"
     export SYNAPSE_API_KEY="<generated-root-api-key>"
     export SYNAPSE_ENCRYPTION_KEY="<generated-fernet-key>"
     export SYNAPSE_ADMIN_DB_PASSWORD="<migration-password>"
     export SYNAPSE_APP_DB_PASSWORD="<runtime-password>"
     python scripts/provision_db_roles.py \
       --runtime-role {{ .Values.config.dbUser }} \
       --admin-role {{ .Values.config.dbAdminRole }} \
       --runtime-password "$SYNAPSE_APP_DB_PASSWORD" \
       --admin-password "$SYNAPSE_ADMIN_DB_PASSWORD" --apply-migrations

   Set config.dbUser to the provisioned DML-only runtime role and
   config.dbAdminRole to the non-superuser migration role, and keep
   config.applyDbSchema=false for runtime pods. Keep bootstrap and migration
   credentials out of the runtime Secret. Details: SECURITY.md.

4. Health:
     kubectl get pods -l app.kubernetes.io/name={{ include "synapse-memory.name" . }}
     engine  -> GET /readiness (fails closed if DB/schema is unavailable)
     gateway -> GET /api/ready (503 until engine + auth are healthy)

Rate limiting is distributed when Redis is configured; otherwise it falls back
to per-replica in-process limits.
